# AGENTS.md — phylox-site

Инструкции для ИИ-агентов и участников, которые правят сайт. Репозиторий
**публичный**, а файлы из корня публикуются как есть на https://phylox.org/ — поэтому
сюда не пишем ничего внутреннего: ни личных данных, ни ключей, ни внутренних планов.

## Что это

Одностраничный сайт-визитка блокчейна **Phylox** (L1 на Go, тикер YLX): что это за
сеть, ключевые параметры (BFT, блок 4 с, финальность в один блок, комиссия
0,0001 YLX, сжигание половины базовой комиссии), статус «до запуска». Цель — честно и
точно описать проект; формулировки о сроках, доходности и гарантиях не добавлять.
Источник фактов — документация основного репозитория Phylox (SPEC, LAUNCH,
VERIFICATION); любые цифры на сайте должны с ней совпадать.

## Стек и структура

Чистый статический HTML/CSS/JS без сборки и зависимостей.

- `index.html` — вся страница; два языка в одной разметке: элементы с `lang="en"` и
  `lang="ru"`, язык выбирается `?lang=` → `localStorage` (`phylox-lang`) → английский.
- `404.html` — страница «не найдено» (тоже двуязычная).
- `assets/site.css` — стили (светлая/тёмная тема через `prefers-color-scheme`).
- `assets/site.js` — прогрессивные улучшения (переключение языка, мета-теги); страница
  должна полностью работать без JS.
- `assets/fonts/` — IBM Plex (woff2, лицензия `OFL.txt`).
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`, `og-image.png` (1200×630).
- `robots.txt`, `sitemap.xml` (обновлять `lastmod` при содержательных правках).
- `CNAME` — домен `phylox.org`; `.nojekyll` — отключает Jekyll. Не удалять.

## Как запустить и проверить

```bash
python -m http.server 8000      # открыть http://localhost:8000/ и ?lang=ru
```

Перед коммитом:
- проверить обе языковые версии и тёмную тему, мобильную ширину (~360 px);
- каждому тексту `lang="en"` должен соответствовать `lang="ru"`, и наоборот;
- мета-теги (`title`, `description`, `og:*`, `twitter:*`) в `index.html` и `META` в
  `assets/site.js` должны совпадать;
- никаких внешних скриптов, трекеров и CDN — шрифты и ресурсы только локальные;
- ссылки и цифры сверены с документацией Phylox.

Автотестов и CI нет — проверка ручная (см. список выше).

## Публикация

GitHub Pages из ветки `main`, корень репозитория (домен из `CNAME`). Всё, что попало
в `main`, через минуту-другую видно на phylox.org — поэтому в `main` только
проверенные правки.
